# WEGYM

WEGYM is a beginner fitness website built with HTML, CSS, and JavaScript.

The goal of WEGYM is to help users find workout videos, workout plans, diet ideas, useful gym equipment, and supplement information in one organized place.

## Features

- Home page
- Workout video page
- Workout plan page
- Diet page
- Equipment page
- Supplement page
- Workout filter buttons by body part
- Workout video IDs for organization
- YouTube workout thumbnails and links

## Workout Categories

The workout video library is organized by body part:

- Chest
- Arms
- Back
- Legs
- Abs
- Shoulders
