# Pilates expansion

Added 31 new classical Pilates exercises without removing or replacing any existing exercise. The page now has 38 exercise cards.

Existing video links and YouTube thumbnails were preserved. New exercise cards use `images/pilates-tutorial-placeholder.svg`, a local thumbnail that cannot break due to a missing YouTube video ID. The cards link to a targeted YouTube tutorial search; these are **not** verified or embedded videos yet. Videos must be checked individually for duration (5 minutes maximum), correct technique, availability, and embedding before marking them complete.

To deploy: extract ZIP, copy the *contents* of WEGYM into the existing GitHub repository, commit and allow Pages to deploy. Keep a backup first.
